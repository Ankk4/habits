
# Habits

Habits form who we are. This is my simple mobile first app to track my daily habits. There are plenty of habit tracking apps out there, but they are usually cluttered with other features and functions or cloud storage for who knows what purposes. So, I wanted a simple mobile first app on my phone where I can easily and fast track down what I am doing on each day.

# Features (tbd)

- Add or remove positive and negative habits
- Track each habit that you have done overtime
- KISS

## Tech stack

- ReactJS UI
- SQLLite

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
