
# Habits

Habits form who we are. This is my simple mobile first app to track my daily habits. There are plenty of habit tracking apps out there, but they are usually cluttered with other features, functions and tracking for who knows what purposes. So, I wanted a simple app on my phone where I can easily track down what I am doing on each day without worrying about where the data goes.

## Tech stack

- ReactJS UI
- SQLLite

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
